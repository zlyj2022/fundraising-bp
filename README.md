# fundraising-bp · 融资商业计划书双模式技能

面向项目方与创业者的融资 BP 助手，主打**天使轮/种子轮**。一个技能，两种模式：

| 模式 | 触发场景 | 产出 |
|---|---|---|
| **设计模式** | "帮我做一份融资 BP"、"我要去见投资人" | 路演 PPT（.pptx）+ Word 尽调版（.docx） |
| **分析模式** | 上传 BP 后问"这份能过吗"、"帮我看看哪里有问题" | 全维度诊断报告（评分卡 + 逐页建议 + 投资人问答预判） |

## 为什么值得用

市面上大多数 BP 工具只解决"排版好不好看"，而投资人拒掉一份 BP 的真实原因通常是：

1. 市场规模只有一个大数，没有测算过程
2. 融资额与承诺的里程碑不匹配
3. 讲不清"为什么是现在、为什么是你们"

本技能把这三类问题写进了工作流：设计时主动规避，分析时优先暴露。

## 技能结构

```
fundraising-bp/
├── SKILL.md                              # 主文件：双模式路由 + 工作流
└── references/
    ├── bp-design-guide.md                # 设计模式：12 页天使轮结构、轮次差异、5 大致命错误
    └── bp-analysis-framework.md          # 分析模式：7 维评分卡、逐页三段式诊断、15 问预判库
```

## 设计模式的 12 页结构

| 页码 | 页面 | 核心任务 |
|---|---|---|
| 1 | 封面 | 一句话定位（≤20 字） |
| 2 | 痛点 | 让投资人感到"这确实疼" |
| 3 | 解决方案 | 产品如何止痛 |
| 4 | 产品演示 / 进展 | 证明东西存在且在动 |
| 5 | 市场规模 | TAM / SAM / SOM 三层测算 |
| 6 | 商业模式 | 怎么赚钱、客单价 |
| 7 | 竞争格局 | 为什么你赢 |
| 8 | 增长策略 | 钱怎么变成增长 |
| 9 | 团队 | 为什么是你们 |
| 10 | 财务概况 | 数字自洽，18-24 个月预测 |
| 11 | 融资规划 | 金额、用途、里程碑三者匹配 |
| 12 | 愿景收尾 | 留下想象空间 |

## 分析模式的评分维度

| 维度 | 权重 |
|---|---|
| 市场机会 | 20% |
| 团队 | 20% |
| 产品 / 技术 | 15% |
| 商业模式 | 15% |
| 财务 | 10% |
| 融资规划 | 10% |
| 叙事与表达 | 10% |

总分档位：**80+** 可投递 / **60-79** 修改后投递 / **<60** 推倒重做。

## 安装

将本仓库目录放入技能目录即可：

```bash
# 用户级（全局可用）
git clone https://github.com/<your-name>/fundraising-bp.git \
  ~/.workbuddy/skills/fundraising-bp

# 或项目级
git clone https://github.com/<your-name>/fundraising-bp.git \
  .workbuddy/skills/fundraising-bp
```

也可直接使用 Releases 中的 `fundraising-bp.skill` 安装包。

## 适用边界

- 不编造数据：缺失信息标记为 `[待补充]`，由创业者补齐
- 不承诺融资结果：估值只给区间与逻辑，最终由市场博弈决定
- 不替代法律意见：TS / SPA 等条款问题建议咨询专业律师
